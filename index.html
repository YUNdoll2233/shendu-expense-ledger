中心费用台账系统

连接你的 GitHub 私有数据仓库，开始管理三个中心的费用。

先使用演示数据 首次建议初始化演示账本。未经公司批准，请不要上传真实付款截图、发票或其他敏感资料。
重要安全提示 GitHub Pages 是公开网页托管服务，GitHub 官方提示不应使用 Pages 处理密码等敏感事务。本版本会在网页内存中使用你输入的 GitHub 令牌，页面脚本可以访问它；同时，账本 JSON 和附件当前以明文保存在 GitHub 私有仓库，不做客户端加密。因此当前只建议连接测试私有仓库、使用虚拟数据。正式账本启用前，必须完成代码审查及公司信息安全审批，并确认公司允许明文资料存储在 GitHub 私有仓库。
令牌仅在当前网页内存中使用，刷新或关闭网页后需要重新输入；不会保存到网站代码或浏览器本地存储。
不知道怎么创建令牌？查看操作说明
  1. 先在 GitHub 创建一个私有仓库，建议命名为 shendu-expense-data。
  2. 打开 GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens。
  3. 创建令牌时，只选择刚才创建的费用数据仓库。
  4. Repository permissions 中将 Contents 设置为 Read and write；其他权限保持 No access。
  5. 设置有效期，创建后复制令牌，粘贴到上方。令牌只显示一次，请自行妥善保管。
